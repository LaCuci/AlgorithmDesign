Second problem:

\begin{notesdefinition}
\textbf{DEF:} Given $G=(V,E)$ undirected, an independent set of size $k$ is a subset of nodes $V'\subseteq V$, $|V'|=k$ such that there is no edge in $E$ with both endpoints in $V'$!
\[
\begin{gathered}
V'\subseteq V,\ |V'|=k:\ \forall u\neq v\in V:\\
(u\in V')\land(v\in V')\Rightarrow\{u,v\}\notin E.
\end{gathered}
\]
\end{notesdefinition}

We have:

\textbf{INDEPENDENT SET (IS)}

\begin{notesproblem}
\text{I:} & \langle G=(V,E),k\rangle\text{, }G\text{ undirected graph, }1\leq k\leq|V|\text{.}\\
\text{Q:} & \text{Does }G\text{ contain an independent set of size }k\text{?}
\end{notesproblem}

The optimization version of this problem requires determining the independent set of max size.

An independent set is somewhat the ``negative'' of a clique, with no edges connecting any two of its nodes. Important
