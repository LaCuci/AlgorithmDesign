\subsection{Worked example of the construction}
\textbf{IDEA:} $t_\phi$ achievable if and only if each clause satisfiable under same $\vec b$.

\textbf{EXAMPLE:}
\[\phi(x_1,x_2,x_3)=\underbrace{(x_1\lor\bar x_2\lor x_3)}_{C_1}\land\underbrace{(x_1\lor x_2\lor x_3)}_{C_2}.\]
$S_\phi$:
\[
\begin{array}{c|ccc|cc|r}
 &\multicolumn{3}{c|}{n}&\multicolumn{2}{c|}{m}&\\
 &x_1&x_2&x_3&C_1&C_2&\\\hline
\delta_1&1&0&0&1&1&10.011\\
\delta'_1&1&0&0&0&0&10.000\\
\delta_2&0&1&0&0&1&1.001\\
\delta'_2&0&1&0&1&0&1.010\\
\delta_3&0&0&1&1&1&111\\
\delta'_3&0&0&1&0&0&100\\\hline
s_1&0&0&0&1&0&10\\
s'_1&0&0&0&2&0&20\\
s_2&0&0&0&0&1&1\\
s'_2&0&0&0&0&2&2\\\hline
t_\phi&1&1&1&4&4&11.144
\end{array}
\]
$2n$: there are exactly 3 1's in each clause position and exactly 2 1's in each variable position.

$2m$: the sum in each clause position is 3 (0 in variable positions).

\textbf{NOTE:}
\[\sum_{i=1}^n(\delta_i+\delta'_i)+\sum_{j=1}^m(s_j+s'_j)
=\bigl(\underbrace{2\cdots2}_{n}\underbrace{6\cdots6}_{m}\bigr)_{10}.\]
NO CARRIES!
