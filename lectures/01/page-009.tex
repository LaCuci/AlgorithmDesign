\subsection{Intractable Problems}
\begin{itemize}
\item Problems of huge practical interest (economics, electronics, AI, learning, biology, logistics).
\item Strong structural properties: a polynomial algorithm for any single intractable problem yields polynomial algorithms for all intractable problems (via reductions, NP-Completeness theory).
\end{itemize}


We'll deal with classes of problems: we need to standardize computational problems as much as possible.
