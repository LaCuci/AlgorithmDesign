\textbf{Correctness:} if $k^*=+\infty$, $A_{\mathrm{SUP}}$ is correct.
Otherwise, by contradiction, if after the for loop, $E'$ does not contain only the edges of a single shortest path $\pi^*$:
\[
\exists e_{\bar i}\in E'\text{ in }E'\text{ not used by }\pi^*.
\]
BUT at iteration $\bar i$ we would have:
\[
A_{\mathrm{KUP}}(\langle G'=(V,E'-\{e_{\bar i}\}),u,z,k^*\rangle)=\mathrm{yes}!
\]
Thus $e=e_{\bar i}$ would have been removed!

$\rightarrow$ We have obtained a poly-time algorithm $A_{\mathrm{SUP}}$ for SUP!
