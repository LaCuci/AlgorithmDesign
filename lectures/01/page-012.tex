An optimization problem can be easily associated to a decision problem
using the following standard technique: augment instance with a natural value representing an upper (MIN) or lower (MAX) limitation to the objective function, for all feasible solutions.

\subsection{Example : K Unweighted Path Problem (KUP)}
\[
\begin{aligned}
\text{I: }&\langle G=(V,E),u,z,k\rangle:\ V\subseteq\mathbb N\text{, finite},\ E\subseteq V\times V,\\
&u,z\in V,\ k\in\mathbb N.\\
\text{D: }&\exists\text{ path from }u\text{ to }z\text{ of length }\leq k?
\end{aligned}
\]
