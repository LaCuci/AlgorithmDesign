\sourceheading[Exercise: Dominating sets]{EXERCISE}
\begin{notesdefinition}
\textbf{DEF:} Given an undirected graph $G=(V,E)$, a \textbf{dominating set} $V'\subseteq V$ is such that
\[\forall v\in V':(v\in V')\lor(\exists\{u,v\}\in E:u\in V').\]
In other words, a node is either in the dominating set or adjacent to a node in the dominating set.
\end{notesdefinition}

Observe that a dominating set is not a vertex-cover.
