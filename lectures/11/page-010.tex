To prove that A-T-T is a 2-approximation, we must relate $\mathrm{OPT}=c(\gamma^*)$ and $c(T^*)$.
\begin{notesresult}
\textbf{LEMMA}\quad $c(\gamma^*)\geq c(T^*)$.
\end{notesresult}
\textbf{PROOF} Let $\gamma^*=\langle v_{i_1},v_{i_2},\ldots,v_{i_{|V|}},v_{i_1}\rangle$.
Remove edge $\{v_{i_{|V|}},v_{i_1}\}$: we obtain a hamiltonian path $H:\langle v_{i_1},v_{i_2},\ldots,v_{i_{|V|}}\rangle$ touching all nodes. $H$ is a Spanning Tree!

We have
\[c(\underbrace{T^*}_{\mathrm{MST}})\leq c(\underbrace H_{\mathrm{ST}})\leq c(\gamma^*)!\]
