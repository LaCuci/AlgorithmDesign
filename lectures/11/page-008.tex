\sourceheading{A 2-APPROXIMATION ALGORITHM FOR $\triangle$-TSP}
We approximated VC by relating $|V^*|$ to $|A'|$ a (maximal) matching of $G$. For $\triangle$-TSP we use a similar approach and relate an optimal tour $\gamma^*$ to a Minimum Spanning Tree (MST) of $G$.
\begin{notesdefinition}
\textbf{DEF:} Given an undirected, connected, weighted $G=(V,E)$, $c:V\times V\mapsto\mathbb N^+$, a Spanning Tree $T=(V,E_T)$ is any connected subgraph of $G$, with $|E_T|=|V|-1$. We set
\[c(T)=\sum_{\{u,v\}\in E_T}c(u,v).\]
\end{notesdefinition}
\begin{notesresult}
\textbf{FACT} A Minimum Spanning Tree (MST) of $G$ can be determined in time $O(|E|\log|V|)$ (e.g. Prim's algorithm \S72 CLRS).
\end{notesresult}
