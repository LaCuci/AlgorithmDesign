\sourceheading{INAPPROXIMABILITY RESULT FOR GENERAL TSP}
\begin{notestheorem}
\textbf{THEOREM} If $\classP\ne\classNP$ there cannot exist a polynomial $\rho(|V|)$-approximation algorithm for TSP, for ANY polynomial-time computable function $\rho(|V|)$.
\end{notestheorem}
Very strong result: observe that even $\rho(|V|)=2^{|V|}$ is poly-time computable (generate 1 followed by $|V|$ 0's).

\textbf{STANDARD TECHNIQUE:} by contradiction: I show that if a $\rho(|V|)$-approximation algorithm exists, I can use it to solve an NPC problem in polynomial time (against the hypothesis $\classP\ne\classNP$).

\textbf{PROOF} We show that if $A_{\mathrm{TSP}}^\rho$ exists, I can solve HAMILTON in polynomial time:

Let $\langle G=(V,E)\rangle$ be an instance of HAMILTON. I create $\langle G'=(V,E'),c:V\times V\mapsto\mathbb N\rangle$ an instance of the optimization TSP problem following the idea of the reduction above:
\[E'=\{\{u,v\}:u\ne v\in V\},\qquad c(u,v)=\begin{cases}
1&\text{if }\{u,v\}\in E,\\
|V|\cdot\rho(|V|)+1&\text{otherwise}.
\end{cases}\]
