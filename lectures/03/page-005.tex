\section{Reducibility between problems}
Intuitively, $\Pi_1$ can be reduced to $\Pi_2$ if any instance $i_1$ of $\Pi_1$ can be 'easily' transformed into an instance $i_2$ of $\Pi_2$ so that a solution to $i_2$ provides a solution to $i_1$.

For decision problems:
\[
i_1\longmapsto f(i_1)=i_2,\qquad\Pi_1(i_1)=\Pi_2(i_2).
\]
The map function $f$ must transform positive instances into positive instances and negative instances into negative instances.

\subsection{Example: reducibility between first and second degree equations}
\[
\Pi_1:\quad\left\{\begin{aligned}
\text{I: }&\langle a,b,x\rangle,\quad a,b,x\in\mathbb C,\\
\text{Q: }&ax+b=0?
\end{aligned}\right.
\]
(decision version of first degree equations)
\[
\Pi_2:\quad\left\{\begin{aligned}
\text{I: }&\langle c,e,f,x\rangle,\quad c,e,f,x\in\mathbb C,\\
\text{Q: }&cx^2+ex+f=0?
\end{aligned}\right.
\]
(decision version of second degree equations)

We can reduce $\Pi_1$ to $\Pi_2$ as follows
\[
i_1=\langle a,b,x\rangle\xrightarrow{f}\langle\underbrace{0}_{c},\underbrace{a}_{e},\underbrace{b}_{f},x\rangle=i_2.
\]
Clearly, $\Pi_1(i_1)=\Pi_2(f(i_1))=\Pi_2(i_2)$.
\[
0\cdot x^2+ax+b=ax+b=0?
\]
