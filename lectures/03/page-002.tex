\section{Theorem and proof: P is a subset of NP} 
$\classP\subseteq\classNP$ ($L\in\classP\Rightarrow L\in\classNP$).

\textbf{Proof:} Let $L\in\classP$. We'll prove $L\in\classNP$ by constructing a poly-time verifier:
Recall that $L\in\classP$ implies that $\exists A_L$ which decides $L$ in time $T_{A_L}(|x|)=O(|x|^k)$.

We can build a 2 input verifier $V_L(x,y)$ uses the algorithm $A_L$ as a subroutine:


\begin{tabbing}\quad\=\kill\>$V_L(x,y)   $\end{tabbing}
\begin{tabbing}\quad\=\kill\> return $A_L(x)$\end{tabbing}


The verifier disregards $y$ and calls $A_L(x)$.

We can prove that $V_L$ is a poly-time verifier for $L$:

\begin{enumerate}
\item $L_V=L$ ($V_L(x,y)=1\Longleftrightarrow x\in L$).
\item $y=\eps$ is a certificate $\forall x\in L$ 
\item y is polynomial in $|x|$: $|\eps|=O(|x|^0):\ k_1=0$
\item $T_V(|x|,|y|)=T_{A_L}(|x|)=O(|x|^k)=O((|x|+|y|)^k)$ ($k_2=k$).
\end{enumerate}
