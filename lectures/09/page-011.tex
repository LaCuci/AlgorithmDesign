\textbf{FACT:} If a graph $G=(V,E)$ contains a matching $A\subseteq E$, then for any vertex-cover $V'\subseteq V$ we have $|V'|\geq|A|$.

\textbf{PROOF:} There must be at least one endpoint of each edge $e$ in $A$ in $V'$, or otherwise $e$ would not be covered.
\sourcefigure[0.75]{assets/09/page-011-matching-cover.png}
\textbf{COROLLARY:} $|V^*|\geq|A|$.

Algorithm A-V-C $(G)$ returns a vertex cover $V'$, with $|V'|=2|A|$.

We have
\[\rho=\frac{|V'|}{\underbrace{|V^*|}_{\geq|A|}}\leq\frac{2|A|}{|A|}=2.\]
\textbf{IMPORTANT:} To prove an upper bound to $\rho$, we always need:
\begin{itemize}
\item a lower bound to $C(s^*)$ --- MINIMIZATION;
\item an upper bound to $C(s^*)$ --- MAXIMIZATION.
\end{itemize}
