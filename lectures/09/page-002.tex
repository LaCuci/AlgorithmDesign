\textbf{2. Restriction of the instance set:} solve the problem on a subset of instances for which there is a polynomial algorithm.

\textbf{EXAMPLE:}
\[\mathrm{2\text{-}CNF\text{-}SAT}\in\classP\]
\[\mathrm{TREE\text{-}VERTEX\text{-}COVER}\in\classP\]
\[\mathrm{SMALL\text{-}TARGET\ SUBSET\ SUM}\in\classP\qquad
\left(t\in O\left(\log^k\left(\sum_{s\in S}s\right)\right)\right).\]
\textbf{3. ``Intelligent'' exhaustive search (O.R. approach):} e.g. branch-and-bound: try to get optimal solution while avoiding to examine all feasible solutions (pruning strategies).

\underline{Heuristic methods}: no upper bound on worst-case running time.

Other heuristics: local-search, tabu-search, simulated annealing: may return nonoptimal solution (local optimum) ($\to$ see OR2).
