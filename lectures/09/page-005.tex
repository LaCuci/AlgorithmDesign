\[C(s^*(i))\leq C(A_\Pi(i))\rho(n)\qquad\text{MAX.}\]

\[C(s^*(i))\geq\frac{C(A_\Pi(i))}{\rho(n)}\qquad\text{MIN.}\]
lower bound on $C(s^*(i))$.

\begin{notesdefinition}
\textbf{DEF:} We say that $\Pi$ is $\rho(n)$-approximable in polynomial time if there exists a $\rho(n)$-approximation algorithm $A_\Pi$ for $\Pi$ running in polynomial time.
\end{notesdefinition}

Hard optimization problems are not all equal w.r.t. approximation: some are $\rho=O(1)$-approximable (in poly. time), some only feature $\rho(n)$ with $\lim_{n\to\infty}\rho(n)=\infty$.

We can often prove that if $\classP\ne\classNP$ there cannot exist a poly-time $\rho(n)$-approximation algorithm for some function $\rho(n)$. (INAPPROXIMABILITY RESULTS).
