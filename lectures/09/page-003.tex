\subsection{Polynomial-time approximation algorithms}
\textbf{4. APPROXIMATION ALGORITHMS:} return a feasible solution whose cost is within a given error margin from the optimal solution in worst-case polynomial time.

\textbf{EXAMPLE:} Return, in linear time, a vertex cover of size at most twice the size of the minimum vertex cover.

\textbf{3 vs 4:} We want hard guarantees on time and solution quality.

(Sometimes a solution obtained through 4. is used as a starting solution for the heuristics of 3.)

\section{Approximation guarantees and schemes}
Let $\Pi$ be an optimization problem with positive integer cost function:
\[\Pi\subseteq\mathcal I\times\mathcal S,\qquad\forall i\in\mathcal I:\mathcal S(i)=\{s\in\mathcal S:i\Pi s\},\]
\[C:\mathcal S\to\mathbb N-\{0\},\qquad\text{and let}\]
\[s^*(i)=\underset{\max}{\operatorname{arg\,min}}\{C(s):s\in\mathcal S(i)\}.\]
