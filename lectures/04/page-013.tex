\subsection{Boolean formula truth assignment}
A truth-assignment is a vector of boolean values $\vec b\in\bits^n$, one for each variable.
The value $\phi(\vec b)$ can be computed in time linear in the formula's size by using the tree. You go up on the tree and progressively associate every internal node with the value obtained from the truth table of the operator of that node according to the values of its children.

A satisfying assignment $\vec b$ is such that the formula under that truth assignment is true : $\phi(\vec b)=1$. If $\vec b$ exists, $\phi$ is said satisfiable.
\subsection{Formula SAT problem formulation}
\[
\begin{aligned}
\text{I: }&\langle\phi(x_1,\ldots,x_n)\rangle,\quad\phi\text{encoding of the boolean formula},\\
\text{Q: }&\text{is }\phi\text{ satisfiable?}
\end{aligned}
\]
\textbf{EXAMPLE:} $\vec b=(0,0,1,1)$.
\[
\phi(x_1,x_2,x_3,x_4)=(x_1\to x_2)\lor(\neg((\neg x_1\leftrightarrow x_3)\lor x_4)).
\]
\sourcefigure[0.55]{assets/04/page-013-satisfying-formula-tree.png}
$\phi$ is satisfiable $[\phi(\vec b)=1]$.

Very similar to BC-SAT (in fact, this is Cook's original problem).
Nonetheless, the reduction is nontrivial.

1. $\mathrm{SAT}\in\classNP$: Trivial: for $\langle\phi(x_1,\ldots,x_n)\rangle$ a candidate certificate is $\vec b\in\bits^n$. $\phi(\vec b)$ can be computed in linear time using the tree representation. 

\begin{itemize}
    \item Check wether the first input represents a tree
    \item check weteher the second input is a truth assignment
    \item Implement bottom up ascent to check if the truth assignment is a positive one. 
\end{itemize}
