The circuit implements a boolean function $y=C(x_1,x_2,\ldots,x_n)$.

For a circuit with $n$ inputs, a truth assignment is $\vec b\in\bits^n$.

\textbf{DEF:} The set of boolean values carried by all wires of a circuit $C$ under a truth-assignment $\vec b$ is called Configuration $\gamma_C$ of $C$ under $\vec b$.

\textbf{DEF:} A boolean circuit $C(x_1,x_2,\ldots,x_n)$ is satisfiable if there exists a truth assignment $\vec b\in\bits^n:\ C(\vec b)=1$.
