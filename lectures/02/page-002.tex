\sourceheading{Classes of decision problems}
\begin{itemize}
\item Problems become elements of sets (classes): need a standard format.
\item $\mathcal S$ is already standardized:
\[
\mathcal S=\{\mathrm{yes},\mathrm{no}\},\qquad\Pi_A:\mathcal I\longrightarrow\{\mathrm{yes},\mathrm{no}\}.
\]
\item Need to standardize $\mathcal I$:
\begin{itemize}
\item From set of abstract structures of arbitrary nature.
\item To set of binary strings $\subseteq\bits^*$.
\end{itemize}
\end{itemize}
\textbf{DEF:} An encoding is an injective function, mapping an abstract set $\mathcal I$ to $\bits^*$:
\[
e:\mathcal I\longrightarrow\bits^*.
\]
