\begin{itemize}
\item Problem classes (categorization with respect to complexity of solution algorithms) $\longrightarrow$ standardization.
\item Abstract decision problems: $\Pi_A:\mathcal I\longrightarrow\{\mathrm{yes},\mathrm{no}\}$.
\item Optimization problems can be paired with a computationally equivalent decision problem $\rightarrow$ add upper/lower bound on cost to instance.
\item If decision problem admits a poly-time algorithm then same holds for optimization problem (AND VICEVERSA).
\end{itemize}
\textbf{CAVEAT:} We can construct optimization problems where the equivalence does not hold! But it holds for totality of interesting problems.

\textbf{Morale:} Concentrate on decision problems.
