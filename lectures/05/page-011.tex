$V_\phi$: (One node for each literal $y_j^i$, $1\leq i\leq m$, $1\leq j\leq3$):
\[V_\phi=\{v_j^i:1\leq i\leq m,1\leq j\leq3\}\Rightarrow|V_\phi|=3m.\]
$E_\phi$:
\[
\{v_{j_1}^{i_1},v_{j_2}^{i_2}\}\in E_\phi\Longleftrightarrow(i_1\neq i_2)\land(y_{j_1}^{i_1}\neq\neg y_{j_2}^{i_2}).
\]
There is an edge between two nodes if their corresponding literals belong to distinct clauses and are not the negation of each other (e.g. $y_{j_1}^{i_1}=x_1$, $y_{j_2}^{i_2}=\bar x_1$).

\textbf{INTUITION:} Two literals corresponding to an edge can be made both true under the same truth assignment.

E.g.,
\sourcefigure[0.8]{assets/05/page-011-compatible-literals.png}
\textbf{EXAMPLE:}
\[
\phi(x_1,x_2,x_3)=(\bar x_1\lor x_2\lor x_3)\land(x_1\lor x_2\lor\bar x_3)\land(x_1\lor\bar x_2\lor x_3).
\]
