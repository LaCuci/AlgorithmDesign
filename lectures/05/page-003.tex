Can this reduction be done in linear time? It depends on how many symbols there can be on a clause associated to any gate. 

Each subexpression uses a number of symbols proportional to the number of wires associated to the corresponding gate. Therefore, the conjunction of all clauses is a formula whose size is proportional to the number of wires in the circuit, so its size is linear in the size of the circuit. 
Therefore, the formula is polynomial time computable.
