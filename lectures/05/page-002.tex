\subsubsection{Step 2 : Build the formula with the clauses}
Clauses are subformulas that describe the behavior (input\-output relation) of every gate. 

To describe the relation we use the equality operator because it is used for the logical description of the behvior of a variable with respect to a combination of other variables.

The combination of the variables is in accordance with the logic of the gate. They can be output wires from other gates or input variables. Some, but noth both, may not be present.  

A Clause is true under a truth assignment if and only if the variable associated to the output of the gate obeys the logical function associated to the gate. 

The subexpression $\Gamma_g$ is true under a truth assignment iff $y_g$ is assigned the correct output value with respect to the values assigned to the gate's inputs.

For each gate $g\in G$ we introduce a specific sub-formula $\Gamma_g$:
\begin{itemize}
\item AND gate:
\sourcefigure[0.3]{assets/05/page-002-and-gate.png}
\[
\Gamma_g:\ y_g\underbrace{\leftrightarrow}_{\text{``equation''}}x_{g_1}\land\cdots\land x_{g_k}\land y_{g_1}\land\cdots\land y_{g_h}.
\]
\item OR gate:
\sourcefigure[0.3]{assets/05/page-002-or-gate.png}
\[
\Gamma_g:\ y_g\leftrightarrow x_{g_1}\lor\cdots\lor x_{g_k}\lor y_{g_1}\lor\cdots\lor y_{g_h}.
\]
\item NOT gate:
\sourcefigure[0.3]{assets/05/page-002-not-gate.png}
\[\Gamma_g:\ y_g\leftrightarrow\neg(z_{g_1}).\]
\end{itemize}

We can then obtain the formula
\[\psi(\vec x,\vec y)=\bigwedge_{g\in G}\Gamma_g.\]

Formula $\psi$ describes a correct configuration under b1 and b2 $C$ \textbf{if and only if}  all the clauses that the circuit is made of  are true at the same time \textbf{if and only if} the relative circuit under the truth assignment b1 and with gate outputs b2 the output values at the various gates match ecactly b2 
\[
\begin{aligned}
\psi(\vec b_1,\vec b_2)=1
&\Longleftrightarrow\text{the values of the outputs of the gates of }C(\vec b_1)\text{ are }(b_2)_g:g\in G\\
&\Longleftrightarrow(\vec b_1,\vec b_2)\text{ is a valid configuration.}
\end{aligned}
\]
