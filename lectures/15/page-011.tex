\subsection{Random outputs and expected approximation}
\begin{notesresult}
REMARK. The use of RANDOM implies that:
\begin{enumerate}
\item The algorithm is NOT deterministic anymore
$\Rightarrow$ returned value and running time are random variables.
\item It may be the case that a randomized algorithm is not always correct
$\Rightarrow$ correctness is an event associated to a probability.
\end{enumerate}
\end{notesresult}
Given an optimization problem $\Pi$, a randomized approximation algorithm $A^R_\Pi(i)$ returns a solution $s\in\mathcal S(i)$ which is a random variable (r.v.) and whose cost $c(s)$ is also a r.v.
