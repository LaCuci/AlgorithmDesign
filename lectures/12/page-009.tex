\subsection{Euler's theorem and finding an Euler tour}
\begin{notestheorem}
\textbf{THEOREM (Euler)} A connected multigraph $G=(V,E)$ is Eulerian if and only if all nodes have even degree.
\end{notestheorem}
\begin{notesresult}
\textbf{FACT} A Euler tour of a Eulerian multigraph can be found in $O(|E|)$ time:
\end{notesresult}
\begin{itemize}
\item Find an initial cycle from an initial node $v$ and remove the edges.
\item Starting from $v$, follow the cycle: if the degree of the current node $>0$:
\begin{itemize}
\item Find a cycle going through node.
\item Splice the cycles together, eliminating the edges.
\end{itemize}
\end{itemize}

\[\langle a,b,c,d,e,f,a\rangle\quad\longmapsto\quad
\langle a,b,d,f,b,c,d,e,f,a\rangle.\]
\subsection{Generalizing the MST approach}
Given an instance $\langle G=(V,E)\rangle$ let us determine a (multi-)subgraph of $G$, $G'=(V,E')$ that is Eulerian and such that
\[\underbrace{\sum_{e\in E'}\underbrace{m(e)}_{\text{multiplicity}}\cdot w(e)}_{\text{cost of the Euler tour}}\quad\text{is small.}\]
