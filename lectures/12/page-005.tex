Since each shortcut can only decrease $c(\mathrm{FPW})$, we have proved that
\[c(\gamma_{T^*})\leq c(\mathrm{FPW})=2c(T^*).\]
Therefore
\[\rho=\frac{c(\gamma_{T^*})}{c(\gamma^*)}\leq\frac{2c(T^*)}{c(T^*)}=2\qquad(c(\gamma^*)\geq c(T^*)).\]
